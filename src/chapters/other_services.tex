\section{Amazon CodeGuru}
\begin{itemize}
    \item An ML powered service for automated code reviews and application performance recommendations
    \item Provides two functionalities
    \begin{itemize}
        \item CodeGuru Reviewer : automated code reviews for static code analysis (development)
        \item CodeGuru Profiler : visibility / recommendations about application performance during runtime (production)
    \end{itemize}
\end{itemize}

%TODO diagram

\subsection{Amazon CodeGuru Reviewer}
\begin{itemize}
    \item Identify critical issues, security vulnerability and hard-to-find bugs
    \item Examples: common coding best practices, resource leaks, security detection, input validation
    \item Uses machine learning and automated reasoning
    \item Hard learned lessons across million of code reviews on 1000s of open source amazon repositories
    \item Supports Java and Python
    \item Integrations with GitHub, Bitbucket and AWS CodeCommit
\end{itemize}

\subsection{Amazon CodeGuru Profiler}
\begin{itemize}
    \item Helps understand the runtime behaviour of your application
    \item Example: identify if you application is consuming excessive CPU capacity on a logging routine
    \item Features:
    \begin{itemize}
        \item Identify and remove code inefficiencies
        \item Improve application performance (e.g reduce CPU utilisation)
        \item Decrease compute costs
        \item Provides heap summary (identify which object using up memory)
        \item Anomaly detection
    \end{itemize}
    \item Support applications running on AWS or on-premise
    \item Minimal overhead on application
\end{itemize}

\section{AWS WorkSpaces}
\begin{itemize}
    \item Managed, Secure Cloud Desktop
    \item Great to eliminate management of on-premises VDI (Virtual Desktop Infrastructure)
    \item Pricing is either on-demand (pay per hour) or monthly subscription
    \item Secure, Encrypted, Network Isolation
    \item Integrated with Microsoft Active Directory
\end{itemize}
%TODO add diagram

\begin{itemize}
    \item Workspaces Application Manged (WAM)
    \begin{itemize}
        \item Deploy and Manage applications are virtualized application containers
        \item Provision at scale and keep the application updated using WAM
    \end{itemize}
    \item Windows updates
    \begin{itemize}
        \item By default, Amazon Workspaces are configured to install software updates
        \item Amazon WorkSpaces with Windows will have Window Update turned on
        \item You have full control over the Windows Update Frequency
    \end{itemize}
    \item Maintenance Windows
    \begin{itemize}
        \item Updates are installed during maintenance windows (you define them)
        \item Always On WorkSpaces: default is from 00h00 to 04h00 in Sunday morning
        \item AutoStop Workspaces: automatically start once a month to install updates
        \item Manual maintenance: you define your windows and perform maintenance
    \end{itemize}
\end{itemize}

\subsection{Amazon Simple Email Service (Amazon SES)}
\begin{itemize}
    \item Fully managed service to send emails securely, globally and at scale
    \item Allows inbound / outbound emails
    \item Repution dashboard, performance insights, anti-spam feedback
    \item Provides statistics such as email deliveries, bounces, feedback loop results, email open
    \item Supports DomainKeys Identified Mail (DKIM) and Sender Policy Framework (SPF)
    \item Flexible IP deployment: shared dedicated and customer-owned IPs
    \item Send emails using your application using AWS console, APIs or SMTP
    \item Use cases: transactional, marketing and bulk email communications
\end{itemize}

\section{Amazon Pinpoint}
%TODO diagram
\begin{itemize}
    \item Scalable 2-way (outbound/ inbound) marketing communications service
    \item Supports email, SMS, push, voice and in-app messaging
    \item Ability to segment and personalise messages with the right content to customers
    \item Possibility to receive replies
    \item Scales to billions of messages per day
    \item Use cases: run campaigns by sending marketing, bulk, transactional SMS messages
    \item Versus Amazon SNS or Amazon SES

    \end{itemize}
\end{itemize}
