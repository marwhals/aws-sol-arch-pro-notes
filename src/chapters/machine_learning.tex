\section{Rekognition Overview}
\begin{itemize}
    \item Find objects, people, text, scenes in images and videos using ML
    \item Facial analysis and facial search to do user verification, people counting.
    \item Create a database of "familiar faces" or compare against celebrities
    \item Use cases:
    \item Labeling
    \item Content Moderation
    \item Text Detection
    \item Face Detection and Analysis (gender, age range, emotions....)
    \item Face Search and Verification
    \item Celebrity Recognition
    \item Pathing (ex: for sports game analysis)
\end{itemize}

\subsection{Amazon Rekognition - Content Moderation}
\begin{itemize}
    \item Detect content that is inappropriate, unwanted or offensive (image and videos)
    \item Used in social media, broadcast media, advertising and e-commerce situation to create a safer user experience
    \item Set a Minimum Confidence Threshold for items that will be flagged
    \item Flag sensitive content for manual review in Amazon Augmented AI (A2I)
    \item Help comply with regulations
\end{itemize}


\section{Transcribe Overview}
\begin{itemize}
    \item Automatically convert speech to text.
    \item Uses a deep learning process called automatic speech recognition (ASR) to convert speech to text quickly and accurately.
    \item Automatically remove Personally Identifiable Information (PII) using Redaction.
    \item Supports Automatic Language Identification for multilingual audio
    \item Use cases:
    \begin{itemize}
        \item transcribe customer service calls
        \item automate closed captioning and subtitling
        \item generate metadata for media assets to create a fully searchable archive
    \end{itemize}
\end{itemize}


\section{Polly Overview}
\begin{itemize}
    \item Turn text into lifelike speech using deep learning
    \item Allowing you to create applications that talk
\end{itemize}

\subsection{Amazon Polly - Lexicon \& SSML}
\begin{itemize}
    \item Customise the pronunciation of words with Pronunciation lexicons
    \item Stylized words: St3ph4ne => "Stephane"
    \item Acronyms: AWS => "Amazon Web Services"
    \item Upload the lexicons and use them in the SynthesizeSpeech operation.
    \item Generate speech from plain text or from documents marked up with Speech Synthesis Markup Language (SSML) - enables more customisation
    \item Emphasising specific words or phrases.
    \item Using phonetic pronunciation.
    \item Including breathing sounds, whispering.
    \item Using the Newscaster speaking style
\end{itemize}


\section{Translate Overview}
\begin{itemize}
    \item Natural and accurate language translation
    \item Allows you to localise content - such as websites and applications - for international users and to easily translate large volumes of text efficiently.
\end{itemize}


\section{Lex + Connect Overview}
\begin{itemize}
    \item Amazon Lex: (same technology that powers Alexa)
    \item Automatic Speech Recognition (ASR) to convert speech to text
    \item Natural Language Understanding to recognise the intent of text, callers
    \item Helps build chatbots and call centre bots
    \item Amazon Connect:
    \item Receive calls, create contact flows, cloud-based virtual contact centre
    \item Can integrate with other CRM systems of AWS
    \item No upfront payments, 80\% cheaper than traditional contact center solutions \textit{Hmmmm......}
\end{itemize}


\section{Comprehend Overview}
\begin{itemize}
    \item For Natural Language Processing - NLP
    \item Fully managed and serverless service
    \item Uses machine learning to find insights and relationships in text
    \item Language of the text
    \item Extracts key phrases, places, people, brands or events
    \item Understands how positive or negative the text is
    \item Analyses text using tokenization and parts of speech
    \item Automatically organises a collection of text files by topic
    \item Sample use cases:
    \item Analyse customer interactions (emails) to find what leads to a positive or negative experience
    \item Create and groups articles by topics that Comprehend will uncover
\end{itemize}


\section{Comprehend Medical Overview}
\begin{itemize}
    \item Amazon Comprehend Medical detects and returns useful information in unstructured clinical text:
    \item Physician's notes
    \item Discharge summaries
    \item Test results
    \item Case notes
    \item Uses NLP to detect Protected Health Information (PHI) - DetectPHI API
    \item Store your documents in Amazon S3, analyse real-time data with Kinesis Data Firehose or use Amazon Transcribe to transcribe patient narratives into text that can be analysed by Amazon Comprehend Medical.
\end{itemize}


\section{SageMaker Overview}
\begin{itemize}
    \item Fully managed service for developers / data scientists to build ML models
    \item Typically difficult to do all processes in one place + provision servers
\end{itemize}


\section{Kendra Overview}
\begin{itemize}
    \item Fully managed document search service powered by Machine Learning
    \item Extract answers from within a document (text, pdf, HTML, PowerPoint, MS Word, FAQs)
    \item Natural language search capabilities
    \item Learn from user interactions / feedback to promote preferred results (Incremental Learning)
    \item Ability to manually fine-tune search results (importance of data, freshness, customer)
\end{itemize}


\section{Personalise Overview}
\begin{itemize}
    \item Fully managed ML-service to build apps with real-time personalised recommendations
    \item Example: personalised product recommendations/re-ranking, customised direct marketing
    \item Example: User bought gardening tools, provide recommendations on the next one to buy.
    \item Same technology used by Amazon.com
    \item Integrates into existing websites, applications, SMS, email marketing systems.........
    \item Implement in days, not months (don't need to build, train and deploy ML solutions)
    \item Use cases; retail stores, media and entertainment
\end{itemize}


\section{Textract Overview}
\begin{itemize}
    \item Automatically extracts text, handwriting and data from any scanned documents using AI and ML
    \item Extract data from forms and tables
    \item Read and process any type of document (PDFs, images)
    \item Use cases:
    \begin{itemize}
        \item Financial Services (e.g, invoices, financial reports)
        \item Healthcare (e.g medical records, insurance claims)
        \item Public Sector (e.g tax forms, ID documents, passports)
    \end{itemize}
\end{itemize}
